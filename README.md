# CODSOFT Python Programming Internship

This repository contains the Python programming tasks completed as part of my **CODSOFT Python Programming Internship**.

## 📌 Tasks Completed

### Task 1 – To-Do List

A Python-based To-Do List application for managing daily tasks.

**Features:**

* Add tasks
* View tasks
* Update tasks
* Delete tasks
* Exit the application

**File:** `todo_list.py`

---

### Task 2 – Calculator

A simple Python calculator that performs basic arithmetic operations.

**Features:**

* Addition
* Subtraction
* Multiplication
* Division
* Error handling for invalid input and division by zero

**File:** `calculator.py`

---

### Task 3 – Password Generator

A Python application that generates random passwords based on the length specified by the user.

**Features:**

* User-defined password length
* Random character generation
* Letters, numbers, and special characters
* Option to generate multiple passwords

**File:** `password_generator.py`

---

### Task 4 – Rock-Paper-Scissors Game

A Python-based Rock-Paper-Scissors game where the user plays against the computer.

**Features:**

* Rock, Paper, and Scissors selection
* Random computer selection
* Winner determination
* Score tracking
* Multiple rounds
* Play again option

**File:** `rock_paper_scissors.py`

---

### Task 5 – Contact Book

A Python-based Contact Book application for managing contact information.

**Features:**

* Add contacts
* View contacts
* Search contacts by name or phone number
* Update contact details
* Delete contacts

**Contact information includes:**

* Name
* Phone number
* Email
* Address

**File:** `contact_book.py`

---
